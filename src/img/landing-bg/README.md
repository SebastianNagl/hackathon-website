# Landing-page background photos

Drop image files (`.jpg`, `.jpeg`, `.png`, `.webp`) into this folder.

Every image here is automatically shown as a full-screen crossfading
slideshow behind the hero on the landing page (`/`), sorted by filename.
If the folder is empty, a curated set of 2026 hackathon photos is used
instead.

No code change or rebuild config is needed — just add the files and
restart the dev server (or redeploy).
